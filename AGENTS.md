# StyleMatch Pro project-state gate

Before planning or modifying anything in this repository:

1. Read `docs/PROJECT_STATE.md` completely.
2. Identify the governing ADR IDs for the requested task.
3. Compare the request with the active architecture and authority boundaries.
4. Stop and report any conflict before editing.
5. Follow the preflight, regression, continuity, physical-acceptance, and hunk-isolation requirements in the ledger.
6. Reference governing ADR IDs in every checkpoint report.
7. Append an acceptance record to `docs/PROJECT_STATE.md` before calling a checkpoint complete.

`docs/PROJECT_STATE.md` is append-only. Never remove or rewrite its decision history. Supersede a decision only by appending a dated replacement approved by the owner.
